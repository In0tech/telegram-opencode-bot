# Творческие возможности бота

Бот умеет работать не только с кодом через OpenCode, но и с OpenAI API напрямую.

Для этих команд требуется:

```env
OPENAI_API_KEY=...
```

Подписка ChatGPT и OpenAI API оплачиваются отдельно.

## /presentation

Создаёт редактируемую презентацию PowerPoint (.pptx).

Пример:

```text
/presentation 10 | Инвесторская презентация AI Cyber Defense Copilot для рынка РФ и СНГ
```

Если количество слайдов не указано:

```text
/presentation Архитектура Anti-DDoS платформы
```

По умолчанию создаётся 8 слайдов. Допустимый диапазон: 3–20.

Презентация формируется через текстовую модель, затем собирается локально библиотекой `python-pptx`. Файл возвращается прямо в Telegram.

## /image

Создаёт изображение через OpenAI Image API.

```text
/image Современный SOC-центр, темный интерфейс, большие экраны, реалистичный стиль
```

По умолчанию:

```env
OPENAI_IMAGE_MODEL=gpt-image-2
OPENAI_IMAGE_SIZE=1536x1024
OPENAI_IMAGE_QUALITY=medium
```

Изображение сохраняется в PNG и отправляется в Telegram как файл.

## /video

Создаёт видео через текущий OpenAI Video API.

```text
/video Камера медленно летит через современный дата-центр, кинематографичный свет
```

Настройки:

```env
OPENAI_VIDEO_MODEL=sora-2
OPENAI_VIDEO_SIZE=1280x720
OPENAI_VIDEO_SECONDS=8
VIDEO_TIMEOUT_SECONDS=900
```

Допустимая длительность Sora API: 4, 8 или 12 секунд.

### Важно

OpenAI пометил Sora API deprecated и запланировал его окончательное отключение на **24 сентября 2026 года**. Поэтому команда `/video` в текущей реализации является временной. После отключения API потребуется заменить video backend, при этом интерфейс Telegram можно оставить тем же.

## /email

Создаёт готовый текст письма.

```text
/email Напиши деловое письмо инвестору после встречи: поблагодари и предложи созвон на следующей неделе
```

По умолчанию письмо создаётся на русском языке, если явно не указан другой язык.

Бот возвращает:

```text
Тема: ...

Текст письма...
```

Отправка email не выполняется автоматически.

## /tarot

Делает случайный расклад из полной колоды 78 карт и интерпретирует его моделью.

```text
/tarot Что принесёт мне завтрашняя встреча?
```

Или указать количество карт:

```text
/tarot 5 | Как будут развиваться мои отношения в ближайшее время?
```

Допустимо 1–10 карт.

Карты вытягиваются локально с использованием криптографического генератора случайных чисел. Для каждой карты случайно выбирается прямое или перевёрнутое положение. Интерпретация подаётся как символический инструмент для размышления, а не как гарантированное предсказание будущего.

## Хранение файлов

Сгенерированные файлы сохраняются в:

```text
STATE_DIR/generated/
```

Например:

```text
~/.local/state/telegram-opencode-bot/generated/
├── presentation_xxxxxxxx.pptx
├── image_xxxxxxxxxx.png
└── video_xxxxxxxxxx.mp4
```

## Модели

Пример:

```env
OPENAI_TEXT_MODEL=gpt-5.6-luna
OPENAI_IMAGE_MODEL=gpt-image-2
OPENAI_IMAGE_SIZE=1536x1024
OPENAI_IMAGE_QUALITY=medium
OPENAI_VIDEO_MODEL=sora-2
OPENAI_VIDEO_SIZE=1280x720
OPENAI_VIDEO_SECONDS=8
```

Модели вынесены в `.env`, поэтому их можно менять без изменения Python-кода.
